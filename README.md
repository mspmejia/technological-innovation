# Technological Innovation — Sitio Web Corporativo

Sitio web oficial de **Technological Innovation**, empresa líder en coaching empresarial y capacitación organizacional en Guatemala.

## Acceso al sitio

**[Ver sitio web](https://mspmejia.github.io/technological-innovation/)**

## Tecnología

- Sitio estático de un solo archivo (`index.html`)
- HTML5 + CSS3 + JavaScript vanilla
- Google Fonts: Montserrat + Inter
- Sin dependencias de build — listo para deploy directo

## Secciones

- Hero animado con partículas y tarjetas flotantes
- Portafolio de servicios (Capacitación, Finanzas, Gestión Org., Riesgos)
- Por qué elegirnos
- Metodología de trabajo (4 pasos)
- Valores de marca
- Formulario de contacto con WhatsApp + email
- Footer con datos de contacto

## Personalización pendiente

- Reemplazar `TUNUMERO` con el número de WhatsApp real (ej. `50256223829`)
- Reemplazar `info@technologicalinnovation.gt` con el correo real
- Opcional: reemplazar el logo SVG con el archivo de imagen oficial

## Deploy

Ejecutar `push_to_github.ps1` desde PowerShell para subir a GitHub Pages.
